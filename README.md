AI Powered Placement Readiness Analyzer.

✅ Resume Parsing

✅ ATS Score Calculation

✅ Skill Extraction

✅ Skill Gap Analysis

✅ Personalized Roadmap

- Python
- Streamlit
- Pandas

## Run Locally

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Project

```bash
streamlit run app.py
```
